# Source lineage and preservation map

## Identity before comparison

The public **PRP v1.0** package was adapted from the **Portable Reasoning Protocol v3.1, Cognous Universal Worker Edition**, then renumbered for its first public Skill release. "1.0" does not mean an earlier, static-only predecessor to "3.1". The public entrypoint and advanced reference must be considered together when comparing content.

Source reviewed for this change: `Portable_Reasoning_Protocol_v3.1_Cognous_Universal_Worker.txt`, supplied by the repository owner. SHA-256 of the supplied bytes:

```text
0e4cbad99ab04c6171690afacb8b7842a7338a9b33e734b25c6daa451a1afac4
```

The source is identified here rather than republished as an employee instruction manual. No private application code, private research corpus or proprietary runtime has been inspected or imported for this update.

Public starting main: `f0bcba6a64209119d33435a2cbcab886f48c0753`.
Existing allocation work continued at: `25f5fd65564139ca351f456e19e35d18b4775531` (PR #6).

These are source/review identifiers, not performance evidence. The original text explicitly describes prompt-level simulation and disclaims perfect compliance. A model-generated control header does not prove that a runtime checked sources, enforced permissions or improved an answer.

## What this update changes

**Retained:** one adaptive protocol; Levels 0-4; separate depth, verbosity and caveat controls; four invariants plus scope preservation; claim modes, world models, type discipline, evidence quality, contradictions, alternatives, negative records and agency.

**Made harder to lose through compression:** the default control settings, minimum-floor rule, cumulative component bundles, mandatory available verification, explicit treatment of blocked checks, and source-preserving version comparisons now appear directly in or are linked from the compact entrypoint. Material negative records are required when context permits, rather than merely suggested "when useful."

**New public operationalization:** stable rule IDs, exact Fast/Standard/Deep/Maximum numeric mapping, explicit selection arithmetic, a separate control-record schema and a pure offline consistency calculator. These are not claimed to be present in the original text or extracted from a private application's XML control record.

**Not asserted:** lossless equivalence in every wording detail; deterministic model behavior; empirical improvement; prevention of all hallucinations; recovery of a previously implemented private enforcement mechanism. The behavioral evaluation cases remain unexecuted until actual model runs are retained.

## Compression policy

Keep the minimum floors, overrides, invariants and final checks in `SKILL.md`, because a model that loads only the entrypoint still needs them. Keep expanded mechanisms, source crosswalks, schemas and evaluation material in references and supporting files. Do not force their loading for clerical work.

Shorter text is not automatically more efficient; more text is not automatically more effective. Measure substantive errors, blocked checks, unnecessary process, latency and token usage using matched conditions before claiming a benefit. Report instruction volume separately from measured inference cost.
